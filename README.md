## 🎯 About This Project

This is my personal portfolio website - a **minimalist, responsive, and interactive** showcase of my work, skills, and achievements. Built with pure **HTML, CSS, and JavaScript**, it features a unique **3D animated robot**, smooth transitions, and a clean black & white aesthetic.

### 🌟 Key Highlights

- ✅ **100% Responsive** - Works flawlessly on all devices (mobile to 4K)
- 🤖 **Interactive 3D Robot** - Unique animated character that follows your mouse
- 🌓 **Dark/Light Theme** - Seamless theme switching with localStorage persistence
- ⚡ **Blazing Fast** - Optimized performance with 60 FPS animations
- 🎨 **Minimalist Design** - Clean, professional black & white aesthetic
- ♿ **Accessible** - WCAG compliant with ARIA labels and keyboard navigation
- 📱 **Mobile-First** - Touch-optimized with no horizontal scrolling

## ✨ Features

### 🎨 Design & UI

- **Minimalist Aesthetic** - Clean black & white design
- **Smooth Animations** - Fade-in effects, carousel animations, scroll reveals
- **Custom 404 Page** - Beautiful error page with animated robot
- **Responsive Typography** - Scales perfectly across all screen sizes
- **Brand-Colored Icons** - Authentic SVG tech stack logos

### 🤖 3D Interactive Robot

The portfolio features a unique **hand-coded 3D robot** with:

- ✅ Mouse-tracking eyes with glow effects
- ✅ Wobbling antenna with spring physics
- ✅ Animated chest panel with pulsing lights
- ✅ Smooth arm swinging and leg swaying
- ✅ Orbiting particles with trails
- ✅ Dynamic facial expressions
- ✅ Theme-aware color changes
- ✅ Fully responsive canvas

### 📱 Responsive Design

```
Mobile First Approach
├── 320px - 480px   → Small Mobile
├── 481px - 767px   → Mobile
├── 768px - 1023px  → Tablet
└── 1024px+         → Desktop
```

- **Zero horizontal scroll** on any device
- **Touch-optimized** with 44x44px minimum touch targets
- **Adaptive layouts** that reflow based on screen size
- **Optimized images** for faster mobile loading

### ⚡ Performance

- **60 FPS animations** using `requestAnimationFrame`
- **Lazy loading** for images
- **Optimized assets** with GZIP compression
- **Browser caching** enabled
- **Reduced motion** support for accessibility

## 🚀 Quick Start

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/divyanshgoyal1/portfolio.git
cd portfolio
```

### 2️⃣ Open Locally

Simply open `index.html` in your browser:

```bash

npx serve

# Or just open the file
open index.html  # macOS
start index.html # Windows
```

### 3️⃣ Visit Your Site

```
http://localhost:8000
```

## 🌐 Deployment

This portfolio is deployment-ready for all major platforms:

### GitHub Pages

1. Push to GitHub
2. Go to Settings → Pages
3. Select branch: `main` or `gh-pages`
4. Save and wait for deployment

**Note:** GitHub Pages automatically handles the 404 page if named `404.html`

### Netlify

1. Connect your GitHub repo
2. Build command: (leave empty)
3. Publish directory: `/`
4. Deploy!

**Note:** `_redirects` file handles 404 routing

### Vercel

1. Import your GitHub project
2. Framework Preset: Other
3. Deploy!

**Note:** `vercel.json` handles 404 routing

### Traditional Hosting (Apache/Nginx)

- Upload all files via FTP
- `.htaccess` file handles 404 routing
- Ensure your server supports `.htaccess`

## 🎨 Customization

### Change Colors

Edit the CSS variables in `style.css`:

```css
:root {
  /* Light Mode */
  --bg-light: #ffffff;
  --text-light: #000000;
  
  /* Dark Mode */
  --bg-dark: #000000;
  --text-dark: #ffffff;
}
```

### Modify Robot

The robot animation is in `script.js` starting at line 450:

```javascript
function drawRobot() {
  // Customize colors, sizes, behaviors
  const colors = getRobotColors();
  // ...
}
```

### Add Projects

Edit the projects section in `index.html` or `projects.html`:

```html
<article class="project-card">
  <div class="project-image">
    <img src="your-image.jpg" alt="Project Name">
  </div>
  <div class="project-content">
    <h3>Your Project</h3>
    <p>Description...</p>
  </div>
</article>
```
